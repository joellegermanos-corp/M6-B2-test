# Trigger de reentrainement Pyrenex
#
# Installation :
#   crontab -e
#   puis copier la ligne ci-dessous.
#
# Frequence : toutes les 6 heures, a l'heure 0 (00:00, 06:00, 12:00, 18:00).
# Le cron lance le script depuis la racine du projet avec le Python du venv.
# Les sorties sont conservees dans logs/retrain.log.

0 */6 * * * cd /opt/pyrenex && /opt/pyrenex/.venv/bin/python /opt/pyrenex/scripts/retrain.py --min-feedback 200 >> /opt/pyrenex/logs/retrain.log 2>&1

# Verification manuelle depuis /opt/pyrenex :
#
# 1. Tester la garde sous le seuil. Cette commande doit terminer avec le code 0
#    et afficher "Skip retrain: N new feedbacks < 200" :
#
#    /opt/pyrenex/.venv/bin/python scripts/retrain.py --min-feedback 200
#
# 2. Verifier que le nombre N correspond aux feedbacks NON CONSOMMES
#    (used_for_training = 0), et non au nombre total de lignes.
#
# 3. Pour un test de declenchement avec un jeu de test ayant au moins 200
#    feedbacks non consommes :
#
#    /opt/pyrenex/.venv/bin/python scripts/retrain.py --min-feedback 200
#
#    Le script doit alors construire un candidat, evaluer la promotion et
#    journaliser la decision dans decisions_log.jsonl.
#
# Diagnostic :
#    tail -f /opt/pyrenex/logs/retrain.log
#
# La garde-seuil est implementee dans scripts/retrain.py. Un nombre inferieur
# a 200 est un cas normal et retourne le code 0 : le cron ne doit pas etre
# considere comme en echec.
